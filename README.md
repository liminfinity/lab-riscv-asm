# Лабораторная работа 1

## Цель

Получить общее представление о системе команд RISC-V путём решения несложной прикладной задачи.

## Вариант задания (4)

Определить количество положительных и отрицательных элементов массива.  
N = 5, M = 6.

## Артефакты

- main.S - программа на RISC-V ASM
- main.c - программа на C
- main.dump - дамп-файл программы на C

## Сборка

```bash
make
```

## Результаты

Была разработана программа на языке C, на основе которой был написан код на языке ассемблера RISC-V.

Код был проверен в симуляторе Venus. После компиляции программы на C был получен ELF-файл, из которого с помощью дизассемблирования был получен dump-файл.

Итоговая структура:

```text
main.S
main.c
Makefile
README.md
main.elf
main.dump
```
